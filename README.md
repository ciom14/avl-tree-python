# avl-tree-python
 
Реализация AVL-дерева на Python: вставка, удаление, поиск соседних ключей.
Решение задачи «AVL 3. Полная реализация» из курса «Авито. Алгоритм 26-27».
 
## Что умеет
 
Дерево изначально пустое и поддерживает команды:
 
| Команда    | Что делает                                              |
|------------|---------------------------------------------------------|
| `add X`    | вставить ключ `X` (если уже есть, ничего не происходит) |
| `del X`    | удалить ключ `X` (если нет, ничего не происходит)       |
| `exists X` | `YES`, если ключ есть в дереве, иначе `NO`              |
| `next X`   | минимальный ключ `>= X` или `None`                      |
| `prev X`   | максимальный ключ `<= X` или `None`                     |
| `root`     | ключ корня или `Empty`                                  |
| `height`   | высота дерева (у пустого 0)                             |
| `print`    | ключи в прямом обходе через пробел или `Empty`          |
 
После каждой вставки и удаления вершины на пути до корня балансируются
(малые и большие повороты, как в классическом AVL).
 
## Формат ввода
 
В первой строке число команд `Q` (1 <= Q <= 10^5), дальше по одной команде
в строке. Ключи целые, по модулю не больше 10^9. Команда `print` встречается
не более 5 раз.

## Формат вывода

На каждую команду exists X выведите YES, если ключ X есть в дереве, и NO иначе.

На каждую команду next X и prev X выведите найденный ключ или None, если подходящего ключа нет.

На каждую команду root выведите ключ корня или Empty, если дерево пустое.

На каждую команду height выведите одно целое число - высоту дерева.

На каждую команду print выведите в одной строке ключи дерева в порядке прямого обхода через пробел или Empty, если дерево пустое.

На команды add и del ничего выводить не нужно. Ответы выводятся по одному в строке в том порядке, в котором шли команды.
